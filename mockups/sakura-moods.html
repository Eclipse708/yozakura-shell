Sakura prompt moods 桜

Three palettes on the same lean two-line prompt, with transient history, a failed command, syntax highlighting, an autosuggestion, and a tmux status bar. Icons are Unicode stand-ins; the real prompt uses Nerd Font glyphs.

1. Yozakura

夜桜

Night blossoms. Near-black with a faint violet cast. Dusty rose for the prompt and anchors, plum for the branch, moonlit blue-grey for directories and flags. Pink is a whisper.

3. Twilight garden

宵の庭

Still black, but the fullest palette: rose prompt, wisteria path, matcha branch and commands, soft gold for strings and modified files. More to read at a glance, more color on screen.

Each mockup reads top to bottom as one session: three finished commands collapsed by transient prompt, then the live two-line prompt with the exit code of the failed command on the right. Any of these can be mixed, for example the sumi-e greys with the twilight branch color.
